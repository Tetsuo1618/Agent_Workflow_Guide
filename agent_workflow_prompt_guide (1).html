Step 1: What Is an AI Agent?

An AI agent is an AI that doesn't just answer questions — it performs tasks using tools, memory, and reasoning across multiple steps.

Key difference: Regular chat = one question, one answer.
An agent = give a goal, the AI figures out the steps to achieve it.

Common Agent Types

Tool-Using Agent

Uses calculators, search, code, APIs to complete tasks

Workflow Agent

Follows a predefined sequence of steps

Reasoning Agent

Breaks complex problems into sub-tasks

Multi-Agent

Several agents working together, each with a different role

Beginner mindset: Think of an agent like a very smart intern. Give clear instructions, context, and boundaries — or they'll guess wrong.

Step 2: The RTCCO Framework

Every great agent prompt has 5 parts: Role, Task, Context, Constraints, Output.

R

ROLE

Who should the AI act as?

T

TASK

What exactly should it do?

C

CONTEXT

What background info is needed?

C

CONSTRAINTS

What are the rules/limits?

O

OUTPUT

How should results look?

EXAMPLE ROLE: You are a social media manager for a fitness brand. TASK: Write 3 Instagram captions promoting our new protein shake. CONTEXT: Our audience is gym beginners aged 18-30. They value authenticity and hate salesy content. The shake is plant-based and chocolate-flavored. CONSTRAINTS: Each caption under 150 characters. Max 3 emojis. Avoid medical claims. OUTPUT: Numbered list. After each, explain why it works for our audience.
Beginner mistake: "Write me some Instagram captions." The AI has no idea about your brand, tone, length, or audience. Generic results.

Step 3: Bad Prompts vs. Good Prompts

Seeing the transformation is the fastest way to learn.

Example 1: Writing Assistant

BAD Write an email to my boss.
GOOD ROLE: You are a professional workplace communication expert. TASK: Draft an email requesting a 3-day extension on the Q3 report deadline. CONTEXT: I have been overloaded with client emergencies this week. My boss values proactive communication. Deadline is this Friday. CONSTRAINTS: Under 150 words. Polite but direct. No excuses. OUTPUT: Subject line + email body. Also suggest 2 alternative opening lines.

Example 2: Coding Agent

BAD Make a Python script for a calculator.
GOOD ROLE: You are a Python developer who writes clean, commented code for beginners. TASK: Create a command-line calculator that handles +, -, *, /, and exponentiation. CONTEXT: This is for a high school coding class. Students have learned basic functions but not classes yet. CONSTRAINTS: Use only functions (no classes). Include input validation so the program doesn't crash. Add comments explaining each function. OUTPUT: Full code in a code block, then explain how each function works in plain English.

Step 4: The Prompt Quality Checklist

Before sending any prompt to an agent, run through this checklist. Click each item to check it off.

Did I assign a specific role?
Is the task a single, clear action?
Did I include audience/context?
Are there word/length limits?
Did I ban things to avoid?
Is the output format specified?
Did I include examples if needed?
Is the tone/voice defined?
Did I set reasoning depth?
Are success criteria stated?
Pro tip: If you check fewer than 7 boxes, your prompt needs more detail.

Step 6: Common Agent Workflow Patterns

Once you master single prompts, chain them into workflows. Here are 3 beginner-friendly patterns.

Pattern 1: The Review Loop

REVIEW LOOP Step 1: Agent A drafts content (uses RTCCO prompt) Step 2: Agent B reviews against criteria (separate "editor" agent) Step 3: If issues found -> back to Agent A with feedback Step 4: Repeat until Agent B approves Use this for: Important emails, code, legal text, proposals

Pattern 2: Research to Synthesis

RESEARCH PIPELINE Step 1: Agent searches and collects 10 sources on topic X Step 2: Agent extracts key findings from each source Step 3: Agent synthesizes findings into a summary table Step 4: Agent drafts recommendations based on patterns Use this for: Market research, competitor analysis, literature reviews

Pattern 3: Decision Tree

DECISION TREE Step 1: Agent classifies incoming request (type A, B, or C) Step 2: If Type A -> Route to Agent specialized in A Step 3: If Type B -> Route to Agent specialized in B Step 4: If Type C -> Route to Agent specialized in C Step 5: Each specialist handles with its own RTCCO prompt Use this for: Customer support triage, content moderation, ticket routing
Your next step: Pick ONE pattern. Write the RTCCO prompt for each agent. Test them individually first, then connect them.
Remember: Even the most complex workflow is just a series of well-written single prompts connected by logic. Master the single prompt first.
